## Notas para mi yo futuro

- Sitio estático: HTML, CSS y un poco de JavaScript. Sin build ni dependencias.
- **No borres el `.nojekyll`**: sin él, GitHub Pages procesa el sitio con Jekyll y se rompe.
- **Añadir un módulo:** duplica un `<li class="card">` en `#lista-modulos`. El atributo `data-ciclo` admite varios ciclos separados por espacios y es lo que usa el filtro.
- **El correo no está escrito entero en el HTML.** Está partido en `data-u` y `data-d`; `main.js` lo recompone al cargar la página.
